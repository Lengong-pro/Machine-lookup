เข้าสู่ระบบผู้ดูแล

เฉพาะคนที่มีสิทธิ์แก้ไขใน GitHub repo ของระบบนี้เท่านั้นที่แก้ข้อมูลได้ คนอื่นใช้ได้แค่หน้าค้นหา
ยังไม่มี token? วิธีสร้าง
  1. เจ้าของระบบเพิ่มคุณเป็นผู้ดูแลก่อน: ใน repo ไปที่ Settings → Collaborators → Add people
  2. ที่ github.com ไปที่รูปโปรไฟล์ → Settings → Developer settings → Personal access tokens
  3. เจ้าของ repo: เลือก Fine-grained tokens → Generate new token → Repository access เลือก Only select repositories แล้วเลือก repo นี้ → Permissions → Contents ตั้งเป็น Read and write → Generate
  4. ผู้ดูแลคนอื่น: เลือก Tokens (classic) → Generate new token (classic) → ติ๊กเฉพาะ public_repo → Generate
  5. คัดลอก token มาวางด้านบน (token จำไว้แค่ในแท็บนี้ ปิดเบราว์เซอร์แล้วต้องใส่ใหม่)

ไฟล์ที่ 2 · status.json

นำเข้า: สถานะเครื่องจักร (DM)

ประวัติแจ้งซ่อม เช่น เลขที่ DM, สถานะ, วันที่พบ, อาการ, สาเหตุ ต้องมีคอลัมน์รหัสเครื่องจักร (เช่น “เครื่องจักร”) เพื่อจับคู่กับรายละเอียด แทนที่ข้อมูลสถานะทั้งหมดด้วยไฟล์ใหม่ ไม่กระทบข้อมูลรายละเอียด
