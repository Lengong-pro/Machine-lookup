เชื่อมต่อ GitHub

เข้าสู่ระบบผู้ดูแลด้วย GitHub token

ระบบยังไม่ได้ตั้ง token กลาง ใส่ GitHub token ของคุณเพื่อจัดการข้อมูล (Admin ตั้ง token กลางได้ในกล่อง “ผู้ใช้งาน” แล้ว Supervisor/Admin จะไม่ต้องใส่ token อีก)
ยังไม่มี token? วิธีสร้าง
  1. เปิด github.com/settings/personal-access-tokens/new
  2. Repository access เลือก Only select repositories แล้วเลือก repo นี้
  3. Permissions → Contents ตั้งเป็น Read and write แล้วกด Generate token
  4. คัดลอก token มาวางด้านบน

ผู้ใช้งานและสิทธิ์

สิทธิ์แต่ละระดับทำอะไรได้บ้าง
  1. ผู้ใช้งานทั่วไป: ใช้หน้า Search Me! และเปลี่ยนรหัสผ่านของตัวเอง
  2. Supervisor: ทุกอย่างของผู้ใช้งานทั่วไป + หน้า Admin สำหรับนำเข้าและแก้ไขข้อมูล
  3. Admin: ทุกอย่าง + จัดการผู้ใช้ สิทธิ์ และ token ระบบ
